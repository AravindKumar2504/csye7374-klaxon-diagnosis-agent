# What I learned (Aravind Sundaravadivelu, in his own words)

1. I learned that an AI agent can choose different tools depending on the problem and the information it finds.
2. I learned that an answer can be correct but still include details that are not supported by the evidence.
3. I learned that when information is missing, the agent should say what it could not check instead of guessing.
4. I learned that testing and checking answers are important because AI can make mistakes.
5. I learned that saving and replaying runs makes it easier to test the agent without running the whole system again.
